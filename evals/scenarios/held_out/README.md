# Held-out scenarios (reserved)

Twelve held-out scenarios for the full-release comparison belong here. They must be sourced from sanitized, authorized real Breadcrumbs sessions or from an independent author who has not read SYSTEM_SPEC §7, and they are excluded from prompt tuning and the smoke subset. Record route, authorship, sanitization and any designer involvement with each file. Until then this directory stays empty; the limitation is reported rather than papered over.
