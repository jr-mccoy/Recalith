- Behavior: `capture(ctx, events)` re-checks ownership and derived identity, then scrubs again. A secret in an identity field refuses that event. Capture applies the environment allowlist, packs segments of at most 256 KiB, and publishes each one (temp write, fsync (`F_FULLFSYNC` on macOS), atomic rename, directory fsync on POSIX). Windows gets one transient-rename retry, waiting at most 20 ms within the soft deadline. Capture acknowledges only after that, then advances the cursor file. Any failure returns `not_captured` with a content-free reason and records a gap. `ingest_ready(ctx, limit=100)` handles each segment in one transaction: events (duplicate vs `source_conflicts`), sessions, environment observations, cursor proposals and one idempotent `ingest` job. It then unlinks the segment. Invalid or foreign segments are quarantined. Normalization replaces invalid Unicode and scrubs before anything else. It keeps 8 KiB head and 8 KiB tail on code-point boundaries with exact original-offset chunks, and puts a marker in the display string. Structured fields win over text within the 64 KiB cap, and oversized messages are partitioned. Typed assertions, the ≤1 KiB error-signature line and runtime versions come only from certified parsers (pytest, unittest, exact `python`/`node --version`). Raw assertions and the `expected_red` hint are dropped with coverage warnings. Registered sources are exact files: a symlink is refused, only complete lines are consumed, and truncation, rewrite or replacement starts a new generation with an explicit gap. Runtime provenance is either declared (`operator_config`, current for its config revision) or observed (`certified_tool`, bound to a registered executable fingerprint). A registered fingerprint change marks older observations stale and advances `guidance_epoch`. Unbound, stale and conflicting values resolve as unknown. Recalith's interpreter is never consulted.
